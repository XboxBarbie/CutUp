# CutUp
The Cut-up Method is implemented in Python!

Before using this program, create a 'Texts' folder and fill it with .txt files you'd like to 'cut up.' Make sure the folder is in the same folder as the program. Don't put the program in the Texts folder. The program will ask the user the number of words, lines, and the style they want. There are three types of styles:

1. Repeat: Will repeat every second random line
2. Thematic: Will print lines with a similar sentiment
3. Random: Will print a random selection of lines

It will also ask for a phrase no matter what style is chosen. You can choose to type a space for non-thematic styles.
